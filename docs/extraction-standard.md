# 抽取標準（v1，2026-11-16，ADR-107–110）

這份標準有三個用途：
- 抽取提示詞照它寫
- 程式規則照它寫
- 判斷者（檢查正確性的 Claude sub agent）照它評分

例子用簡短的轉述，不放整段原文（repo 是公開的）。每條後面的括號是 `docs/definitions-decisions.md` 的題號。

## 1. 這一筆是什麼

1. **一頁有幾個獎學金就存幾筆**（A1 C、ADR-108）
   - 每筆只放它自己的申請期、金額、國籍、學位。
   - 例：一頁同時介紹 Erasmus 獎學金和學校的區域補助，就存成兩筆。
   - 錯：把區域補助的 600 歐元放進 Erasmus 那一筆。
2. **頁面沒有提供任何獎學金，就不是獎學金**（A2 C）
   - 抽取結果標成「不是獎學金」，程式停用這個來源，並列在每天的報告裡。
   - 例：學院頁面只有入學資訊，原文寫明不提供補助。
3. **自費生的輪次**照樣是申請期，`funding=self_funded`（11-16 選 1A）。判斷者不算錯。

## 2. 申請期

1. **只存最新一屆的日期**（B1 B）
   - 原文同時有已過的一屆和下一屆時，只存下一屆。
   - 下一屆還沒公布日期、但原文說了何時公布，要記下這句話。
   - 錯：只存已過的 2026/3/15，漏掉「下一屆 2026/10/15 開放」。
2. **屆別照抄原文**（B2 A）
   - 例：原文寫「2026-2028 cohort」，就填 2026-2028。
   - 錯：自己改寫成 2027。
3. **沒寫年份的日期**（B3 B、ADR-110）
   - AI 不填年份。
   - 程式取今天以後最近的那一天，標「年份推估」。
4. **日期的種類**（ADR-105、B4 A、B5 B、11-16 選 2A）

   | 種類 | 什麼時候用 |
   | --- | --- |
   | `scholarship` | 申請這個獎學金的期間，包括和入學一起申請、隨入學一起審核 |
   | `admission_only` | 只有入學。包括獎學金是入學後才申請（例如修滿 60 學分、第二年起依成績給），以及原文寫明這段期間拿不到這個獎學金 |
   | `document` | 補件、上傳文件、成績或證明的期限 |
   | `payment` | 繳費、訂金，包括早鳥繳費期限（錯過就沒有折扣也一樣） |
   | `other` | 面試、放榜、報到 |

## 3. 金額

1. **只存這個獎學金給的錢**：其他補助的錢歸到它自己那一筆（1.1）。
2. **百分比存在 `percent`**（C1 B）
   - 例：學費減 50%，存成 `percent=50`、`value` 空白。
   - 錯：存成 50 歐元。
3. **學費減免只存「減多少」**（C2 A）
   - 原文只寫學生要付的金額時，不存數字，寫進補助內容。
   - 原文同時寫了原價和實付時，可以存兩者的差額。
   - 錯：把實付的 15,500 存成補助。
4. **Erasmus 的參與費用算學費補助**（C3 A）
   - 例：參與費用 9,000 歐元由獎學金支付，存成 `tuition_coverage` 9,000。
5. **只有第一年才有的減免或折扣**（C4 C）：期間填 `first_year`。
6. **兩群人金額一樣就合併成一筆**（C5 A）
   - 適用對象寫兩群。
   - 例：Programme 和 Partner 都是每月 1,400，存成一筆，適用對象寫兩群。
7. **同一筆錢不要用每月和總額各寫一次**（ADR-103）：程式會拿掉重複的總額。

## 4. 國籍

1. **原文寫群組名時，填群組名**（D1 C、ADR-109）
   - 例：歐盟、EEA、瑞士、Erasmus+ Programme／Partner countries、African Union。
   - 程式展開成國碼。
   - 不認識的群組（例如學校自訂的 Tier 1），存群組名，國籍標待確認。
2. **「只收繳學費的學生」不算國籍條件**（D2 B）
   - 寫進國籍條件的文字，國籍範圍照原文的國家判斷。
   - 原文沒寫國家，就是不清楚。
3. **「只限非歐盟／EEA」**：排除歐盟／EEA 群組（extract-13 起）。
4. **Erasmus 學程網站沒寫國籍**：用 EACEA 目錄頁的依據（ADR-053），判斷者不算錯。

## 5. 今年有沒有開（`offered`）

1. **`no` 只有在原文明寫「目前不提供、這一屆沒有、已停辦」時才填**（E1 B）
   - 沒有明寫就填 `unclear`。
   - 錯：原文寫 2026–2028 沒有，就推論下一屆也沒有。
2. **寫明不提供時**，網頁上的金額與說明標「過去的資訊」（E2 B）。

## 6. 學位

1. **學位是拿獎學金去讀的學位**，不是申請人已有的學歷。
2. **不是學士、碩士、博士的課程填 `other`**（F1 B）
   - 例：進階研究所文憑（APD）、短期課程。
   - 錯：把 APD 填成博士。
